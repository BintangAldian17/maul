# Maulana Rizky Portfolio

Next.js App Router foundation for migrating `maulana-portfolio.html`. It includes a minimal GSAP client component and production metadata, `robots.txt`, `sitemap.xml`, and web manifest.

## Run

```bash
npm install
npm run dev
```

Before deployment, set `NEXT_PUBLIC_SITE_URL` to the real public domain (see `.env.example`).
